# GitHub Actions secrets for scheduled ingestion

Add these six secrets to the repository before triggering the workflow.

**Where to add them:** GitHub repo → Settings → Secrets and variables → Actions → New repository secret

## Required secrets

- `DATABASE_URL` — Supabase Session pooler connection string
- `LASTFM_API_KEY` — from https://www.last.fm/api/account/create
- `LASTFM_USERNAME` — last.fm username (steynvg)
- `SPOTIFY_CLIENT_ID` — from Spotify Developer Dashboard
- `SPOTIFY_CLIENT_SECRET` — from Spotify Developer Dashboard
- `SPOTIFY_REFRESH_TOKEN` — generated by running `uv run python scripts/spotify_auth.py` locally

The values are the same as in your local `.env` file — copy them over.

## Testing the workflow

After adding secrets, trigger the workflow manually: Actions tab → Scheduled ingest → Run workflow → main → Run workflow. Watch the run; the ingest step should print scrobble counts and the playlist step should report tracks added.
